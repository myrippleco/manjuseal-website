# Manju Seal — personal site

Static one-page bio site for manjuseal.com, matching the Terra Impact visual design. Plain HTML/CSS/JS, no build step, hosted on GitHub Pages.

## Structure
- `index.html` — all page content
- `style.css` — all styling (shares design tokens with the Terra Impact site)
- `script.js` — mobile nav toggle + footer year
- `assets/` — Terra Impact logo, favicons, headshot (add `headshot.jpg` here)
- `CNAME` — tells GitHub Pages to serve this repo at manjuseal.com
